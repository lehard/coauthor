## ADDED Requirements

### Requirement: Подпись ГлавAI в настройках
Страница `/settings` MUST показывать под последним разделом строку «ИИ-соавтор создан в ГлавAI» мелким вторичным текстом, где «ГлавAI» — ссылка на `https://glavai.ru/cases/soavtor?utm_source=soavtor-app&utm_medium=credit`, открывающаяся в новой вкладке. Строка MUST NOT быть разделом в списке разделов и MUST NOT запрашивать API или другие хосты при показе. Полка, корзина, окно истории, чат соавтора и экран входа MUST NOT показывать эту подпись.

#### Scenario: Подпись внизу настроек
- GIVEN пользователь открыл `/settings`
- WHEN он прокручивает страницу до конца
- THEN под разделом «Ваши тексты» MUST стоять строка «ИИ-соавтор создан в ГлавAI»
- AND «ГлавAI» MUST вести на `https://glavai.ru/cases/soavtor?utm_source=soavtor-app&utm_medium=credit` с `target="_blank"` и `rel="noopener"`
- AND в списке разделов MUST NOT появиться нового пункта

#### Scenario: Подпись читается в каждой теме
- GIVEN выбрана тема «Утро», «Бумага» или «Вечер у лампы»
- WHEN открыт низ `/settings`
- THEN цвет строки и ссылки MUST браться из семантических токенов темы и проходить проверку контраста дизайн-системы

#### Scenario: Без запроса при показе
- GIVEN открыта вкладка сети браузера
- WHEN пользователь открывает `/settings`
- THEN показ подписи MUST NOT вызывать запросов к `glavai.ru` и к API

#### Scenario: Нет подписи на рабочих экранах
- GIVEN пользователь на полке, в корзине или в окне истории с открытым чатом
- WHEN читается экран
- THEN строки «ИИ-соавтор создан в ГлавAI» и ссылки на `glavai.ru` MUST NOT быть

#### Scenario: Узкий экран
- GIVEN ширина окна 375 px
- WHEN открыт низ `/settings`
- THEN строка MUST быть видна целиком без горизонтальной прокрутки
