# Задачи

## 1. Первый экран и вопросы

- [x] 1.1 В `Hero` и контенте главной поставить согласованные заголовок, текст, CTA и подпись. Показать читаемый фрагмент настоящего кадра с правкой реплики Коли. Заменить проверки прежнего противоречия проверками текста, кадра, подписи, видимости CTA и входа при 390 px.
- [x] 1.2 Переделать песочницу в три раскрываемых вопроса, сопоставить каждый ответ с данными «Тихой воды». В проверках готового HTML и браузера проверить все три пары, раскрытие клавиатурой и чтение без JavaScript. Удалить ожидания набора текста и переходов к будущим функциям.

## 2. Знания и разбор ответа

- [x] 2.1 Собрать блок о драматургии по бизнес-интенту. Диалог о братьях пометить как редакционный пример. Проверить в пререндере дословные реплики и согласованный текст команды, а при отключённых скриптах — видимость всего диалога до раскрытия.
- [x] 2.2 Сделать раскрытие под ответом и переход со слов «рука высунется» к ранней сцене. Проверить содержание всех пометок, включая подтекст и взгляд зрителя. Обновить браузерную проверку для касания, клавиатуры, изначально закрытого и уже открытого разбора, возврата к свёрнутому виду и режима уменьшенного движения.

## 3. Свой черновик, команда и заявка

- [x] 3.1 Встроить в `Home` блок о черновике, обращение команды с эпиграфом, форму и короткий FAQ в согласованном порядке. Проверить пять форматов, маршрут к форме, работающий вход и корректное расположение подсказок FAQ. Сверить обращение с согласованным текстом.
- [x] 3.2 Снять с главной самостоятельные устаревшие витрины и их проверки. Актуализировать проверку порядка разделов и отсутствия слова «концепт» во всех формах в видимом и доступном тексте главной, включая раскрытия и подписи. Проверить все ссылки на ресурсы после изменений и сохранить проверки формы, документов и бюджета сборки.

## 4. Сквозная проверка

- [x] 4.1 Выполнить `npm run build --prefix site` и `npm run check:behaviour --prefix site` на собранной локальной странице с заданными `SITE_URL` и `CHROMIUM_PATH`. Проверить путь от первого экрана до заявки без открытия примеров, затем оба способа открыть разбор на телефоне и десктопе.
- [x] 4.2 Осмотреть главную при 390 и 1440 px. Убедиться, что текст реплики и правки читается, фокус и раскрытые пометки видны, страница не прокручивается по горизонтали, а без JavaScript читаются основные блоки. Зафиксировать результаты перед верификацией.
