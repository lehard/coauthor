# Proposal: тесты загрузки промптов агентов и ошибка навыка с файлом

Источник: `business-intents/prompt-skill-tests.md` (решения владельца 2026-11-17).

## Why

На `agno/agents/prompts.py` нет ни одного теста: сломанный `SKILL.md` или регрессия в загрузке видны только тогда, когда API не стартует. Кроме того, спека `api/agents` («Соавтор», «Неверный заголовок навыка») требует, чтобы старт падал с ошибкой, называющей файл и причину. На деле Agno `LocalSkills` сам отклоняет навык без `description`, с пустым `description`, с `name`, не равным каталогу, и с битым заголовком. Отклоняет он своей `SkillValidationError`, где пути к файлу нет.

## What Changes

- `agent_skill` перехватывает `SkillValidationError` Agno и бросает `RuntimeError` с путём к `SKILL.md` и причиной Agno (`raise … from error`). Промпт не подменяется.
- Новый `agno/tests/test_prompts.py`, без базы и модели:
  - настоящий навык соавтора загружается: имя, описание, тело;
  - модуль соавтора передаёт агенту `agent_prompt("coauthor")`;
  - отказы с файлом и причиной: нет файла, нет или пустое `description`, чужое `name`, битый заголовок, пустое тело;
  - каждый каталог в `agno/skills/` загружается по своему имени.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Спека `api/agents` («Соавтор»: «Нет навыка», «Неверный заголовок навыка») уже требует это поведение; change приводит к нему код и добавляет тесты. Поэтому `skip_specs: true`.

## Scope

- `agno/agents/prompts.py` — перехват ошибки Agno в `agent_skill`.
- `agno/tests/test_prompts.py` — новые тесты.

## Non-goals

- Поведение модели по промпту и полный запуск агента.
- Изменения Agno `LocalSkills`.
- Новые проверки навыков сверх тех, что уже делают Agno и `agent_skill`.

## Impact

- Сообщение об ошибке старта с плохим навыком становится понятнее: в нём есть путь. Тип исключения у вызывающих (`app/main.py`, экзамен маршрутизации) — `RuntimeError`, как и у остальных отказов `agent_skill`.
- API, данные и поведение агентов не меняются.
