## ADDED Requirements

### Requirement: Разбор файла беседы
Файл с `purpose` `chat` формата импорта (Fountain, FDX, STARC, DOCX, TXT) MUST разбираться теми же правилами, что файл импорта: «Абзацы сценария из файла», «Персонажи и локации из импорта», «Отказ импорта STARC», «Пропущенное при импорте STARC». Ядро делает это только по вызову соавтора (`api/agents`). `POST /api/v1/drafts/{id}/import` MUST по-прежнему отвечать `422` на файл с `purpose` `chat`.

#### Scenario: Маршрут импорта и файл чата
- WHEN `POST /api/v1/drafts/{id}/import` получает `file_id` файла с `purpose` `chat`
- THEN ответ MUST быть `422`, и драфт MUST NOT меняться

### Requirement: Новый драфт из файла беседы в ядре
Ядро MUST создавать из файла беседы новый драфт истории файла: копию заданного драфта этой истории по правилам создания драфта, у которой текст сценария заменён текстом из файла, а недостающие персонажи и локации добавлены. Заданный и другие драфты MUST NOT меняться. Запертая основа MUST NOT мешать: новый драфт создаётся незапертым.

#### Scenario: Новый драфт из Fountain беседы
- GIVEN в истории «Паром» драфт 1 с персонажем «Вера», и к беседе приложен Fountain-файл с тремя сценами и репликами «ВЕРА» и «ОЛЕГ»
- WHEN ядро создаёт из него драфт «Паром — правка» на основе драфта 1
- THEN в истории MUST появиться драфт «Паром — правка», текст сценария которого совпадает по абзацам и типам с текстом, который даёт импорт этого файла кнопкой, а у трёх заголовков сцен разные `uid`
- AND в новом драфте MUST быть «Вера» и добавленный «Олег», а текст и документы драфта 1 MUST остаться прежними

#### Scenario: Основа заперта
- GIVEN драфт 1 заперт
- WHEN ядро создаёт новый драфт из файла беседы на основе драфта 1
- THEN новый драфт MUST появиться незапертым, а драфт 1 MUST остаться запертым и прежним

#### Scenario: STARC с пропуском
- GIVEN `.starc` беседы, где у локации «Колиба» нет профиля
- WHEN ядро создаёт из него новый драфт
- THEN драфт MUST появиться без «Колибы», а результат MUST называть пропущенную локацию «Колиба»

### Requirement: Новая история из файла беседы в ядре
Ядро MUST создавать из файла беседы историю пользователя по правилам «Новая история из файла»: текст сценария из файла, персонажи и локации, копия файла в новой истории с `purpose` `import`. Файл беседы MUST оставаться в прежней истории с `purpose` `chat`.

#### Scenario: Новая история из файла беседы
- WHEN ядро создаёт историю «Паром 2» из Fountain-файла беседы
- THEN у пользователя MUST появиться история «Паром 2» с текстом сценария из файла и копией файла с `purpose` `import`
- AND файл беседы MUST остаться в прежней истории с `purpose` `chat`

### Requirement: Сцены файла беседы в ядре
Ядро MUST отдавать сцены файла беседы: список сцен (номер с 1, текст заголовка, число абзацев) и абзацы одной сцены `{type, text}` в том виде, в каком они попали бы в текст сценария при импорте, с переносами строк внутри абзацев. Номер вне списка MUST давать отказ, называющий число сцен.

#### Scenario: Сцены файла с переносом строки
- GIVEN Fountain-файл беседы, во второй сцене которого персонаж «ДАРЬЯН» и строки «Фыва» и «ывафы» сразу под ним
- WHEN ядро отдаёт абзацы сцены 2 этого файла
- THEN среди них MUST быть `{type: "character", text: "ДАРЬЯН"}` и `{type: "dialogue", text: "Фыва\nывафы"}`

#### Scenario: Сцены нет
- GIVEN в файле беседы три сцены
- WHEN ядро отдаёт абзацы сцены 4
- THEN MUST быть отказ, называющий число сцен файла

### Requirement: Отказ разбора файла беседы
Файл другой истории, формат не из списка импорта (PDF, MD), битый файл или отказ разбора MUST давать отказ с причиной; у формата не из списка причина MUST перечислять форматы импорта. При отказе MUST NOT появляться ни драфта, ни истории, ни документов, ни файла. Разбирать такой файл как простой текст MUST NOT.

#### Scenario: PDF не импортируется
- WHEN ядро создаёт новый драфт или новую историю из `Эпоха.pdf` беседы
- THEN MUST быть отказ, перечисляющий Fountain, Final Draft, STARC, DOCX и TXT, и MUST NOT появиться ни драфта, ни истории

#### Scenario: Битый FDX беседы
- WHEN ядро создаёт новый драфт из FDX беседы с нарушенным XML
- THEN MUST быть отказ с причиной, и драфт MUST NOT появиться
