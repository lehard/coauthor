# Design: в «Поделиться» только ссылка «почитать»

## Context

Мотивация — `proposal.md`. Окно «Поделиться» (`web/src/screens/project/ShareDialog.tsx`) сейчас собирает форму приглашения (`InviteForm`, только владельцу), список участников и приглашений (`useMembers`, `MemberRow`), раздел ссылки (`ReadLinkSection`, владельцу и соавтору) и «Выйти из истории». Кнопка `ShareDialog` стоит в `Navigator.tsx` для всех ролей. Справка соавтора — раздел «О сервисе «Соавтор»» в `agno/skills/coauthor/SKILL.md`.

## Goals / Non-Goals

**Goals:** убрать с экрана всё, что ведёт к участникам, с наименьшей правкой; вернуть позже без переписывания.

**Non-Goals:** сервер, данные, экраны по роли, полка, `web/src/data/sharing.ts` (операции участников остаются в источниках данных — их использует только убранная часть окна).

## Decisions

### 1. Удалить из окна части участников, а не прятать флагом

`ShareContent` оставляет заголовок, описание о ссылке и `ReadLinkSection`; `InviteForm`, `MemberRow`, список приглашений и выход удаляются из файла. Флаг или настройка «участники включены» отвергнуты: это новая конфигурация и ветвление, которое тоже надо тестировать; вернуть части можно из истории git (change `story-sharing`).

### 2. Кнопку видят владелец и соавтор

Раздел ссылки уже показывается только при `can.edit`; кнопку `ShareDialog` в навигаторе тоже показываем при `can.edit`, иначе рецензент и читатель открыли бы пустое окно.

### 3. Справка соавтора

Пункт «совместная работа» заменяется коротким: «Поделиться» → «Ссылка почитать» (текст сценария открытого драфта без входа, можно отключить); приглашать соавторов, редактора и читателей пока нельзя. Строка о роли спрашивающего из справки уходит; роль по-прежнему приходит в контексте экрана, и инструменты отказывают по ней кодом.

## Risks / Trade-offs

- [Участник, приглашённый через API, не увидит в окне «Выйти из истории»] → на бете маловероятно; приглашения через API принимаем как риск (intent).
- [Код операций участников в `web/src/data` без пользователей] → оставляем: он маленький, покрыт типами и вернётся вместе с окном.
