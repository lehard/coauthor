# Proposal: в «Поделиться» только ссылка «почитать» на время беты

Источник: `business-intents/share-read-link-only.md` (решение владельца 2026-11-15).

## Why

Сервис ещё не протестирован как следует, и владелец со Львом решили (2026-11-15) сначала стабилизировать то, что есть. Участники истории с ролями из релиза v0.3.26 открывают тестировщикам много новых путей. Ссылка «почитать» — самая простая и уже проверенная на сервере часть. Откатить релиз без потери данных нельзя (миграция `0019_story_sharing` только вперёд), поэтому участников прячем на экране, а сервер оставляем.

## What Changes

- Окно «Поделиться» показывает только раздел «Ссылка почитать» открытого драфта; приглашение по почте, роли, список участников, «Отозвать», «Убрать» и «Выйти из истории» с экрана уходят.
- Кнопка «Поделиться» видна только тем, кто может управлять ссылкой (владелец и соавтор); другим окну нечего показать.
- Справка ИИ-соавтора о совместной работе говорит только о ссылке «почитать»; на вопрос о приглашении соавторов или редактора соавтор говорит, что пока можно дать почитать по ссылке, а приглашать участников нельзя. Строка о роли спрашивающего уходит из справки.
- Контекст-пак: участники описаны как скрытые на экране на время беты; бэклог этапа 2 получает запись о возврате приглашений.
- Сервер, база, маршруты участников и экраны по роли не меняются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web/workspace`: «Окно «Поделиться»» с приглашениями убирается (REMOVED), вместо него «Окно «Поделиться» со ссылкой» — только ссылка «почитать», кнопка видна владельцу и соавтору.
- `api/agents`: «Справка о совместной работе» — только о ссылке «почитать».

## Scope

- `web/src/screens/project/ShareDialog.tsx`, `agno/skills/coauthor/SKILL.md`.
- Мастер-спеки `web/workspace` и `api/agents`; `openspec/context/01-product-context.md`, `openspec/context/backlog-stage-2.md`.
- Проверка: `./scripts/validate.sh`, `git diff --check`, браузер на локальном стенде (1440 и 375 px), один ответ соавтора глазами.

## Non-goals

- Изменения сервера, базы, миграций, маршрутов участников и приглашений; отказ сервера в приглашениях через API.
- Изменения ссылки «почитать», страницы `/read/:key`, конфликта сохранения, присутствия и экранов по роли.
- Откат релиза v0.3.26.

## Impact

- Только фронтенд окна «Поделиться» и текст промпта соавтора; API и база без изменений, серверные тесты те же.
- Через API владелец технически может пригласить участника вручную; на время беты риск принят.
